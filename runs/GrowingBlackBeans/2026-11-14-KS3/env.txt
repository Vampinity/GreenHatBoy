# runKS3 — scripted Kokiri route, start 3 of 3. t134-gbb9 (01.219.925), no new build.
# Same switches as runGS1 (counts only: GPFIFO + submission stats), plus the test harness:
#   EDEN_TEST_SCRIPT=kokiri-four-stops.txt   the game walks itself: house, stops A-D, 62 s each
#   EDEN_TEST_DISCARD_SAVE=1                 autosaves go to a throwaway copy, so your house save stays on top
# The script was made from runKW2 (gbb-tools/steer/kokiri-four-stops/). It's in this folder.
#
# BEFORE YOU START
#   1. Copy kokiri-four-stops.txt from this folder to /data/eglantineps5/ on the console (next to env.txt).
#      NEW after KS1: replace the one KS1 used. At each stop Link may now turn in small steps until the view
#      matches KW2's (D faced ~45 deg off in KS1). Same file for KS2 and KS3.
#   2. Your house save must be the top entry of the load list (it is, if nothing else saved since KW2).
#   3. No capture video needed. Don't touch the controller once the title shows: the script presses
#      everything, and a stick or button you touch between its presses takes over.
#
# WHAT YOU'LL SEE (about 7 minutes after the title)
#   Title -> Continue -> load -> Link runs out of the house and hops down, walks to A, turns, stands ~65 s;
#   then B, C (the rock), D (the sign), the same way. At each stop: a camera snap, a small turn, another snap.
#   At D Link may turn a few small steps (snap, turn, snap) before standing still.
#   After D's stand nothing more happens: quit the game then (Link standing at the sign for over a minute).
#   Watch for: Link stuck against something for more than ~10 s, or a stop facing clearly wrong
#   (C should look out over the cliff, D at the sign). Note the stop and the time, roughly.
#
# AFTER: copy the logs folder as usual (eden_log.txt + logs/). KS2 and KS3 can run back to back.
