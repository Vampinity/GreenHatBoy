# Getting help

- **A question about install or the first start:** ask in [Q&A](https://github.com/Vampinity/GreenHatBoy/discussions/categories/q-a).
- **A crash or a glitch:** fill in the [Crash or glitch form](https://github.com/Vampinity/GreenHatBoy/issues/new?template=crash.yml).
- **Your results, videos or screenshots:** post them in [Show and tell](https://github.com/Vampinity/GreenHatBoy/discussions/categories/show-and-tell).

Please always tell us:

- Which PS5 you have (base, Slim or Pro) and its firmware.
- Which build and which settings file you use.
- What you did and what you saw.

Do not share game files, keys or firmware, or links to them. Keep story details vague.
