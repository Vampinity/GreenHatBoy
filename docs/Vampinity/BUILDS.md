# Builds (Vampinity's test builds)

Every test build, newest first: what it added, what it was built on and how it tested. Copied from the owner's
local build list on 12 Nov 2026 (10:45), with local paths and private details taken out. Nothing else is changed.
The rows T135 to T183 were added on 14 Nov 2026, shortened, from the same list and the build notes; their
test counts are scripted starts unless a row says the build was played by hand.

Names are `T<number>-<main change>`; the number kept counting from the old `ocarina-next` builds. Patch numbers
(four digits, for example `0586`) and switch names (`EDEN_...`) are written in full, so a search finds them.
Switches are listed one row each in [SWITCHES.md](SWITCHES.md). "Built on" is the base the build list names
("T133 + ...", "T19 plus ..."); `-` where it names none. Findings behind the newest verdicts are in [findings/](findings/).

## Notes on two builds

**T120 is the public testers' build (11 Nov 2026).** Published on Vampinity's word: branch `ocarina-dev-t120` (e40829e, the scrubbed tree) on github.com/Vampinity/Eglantine-PS5-, pre-release "Ocarina dev build T120 (for testers)", tag `ocarina-dev-t120`, asset `EglantinePS5-Ocarina-dev-T120.zip` (the checked stage + README-T120.md), a comment on issue 21. Nothing else is pushed or published for T120 or T116.

**T123 is HELD (11 Nov 07:14): do not install.** waveydude reported on issue 21 that his T120 + Build O branch crashed on his console two minutes after loading (std::bad_alloc on GPUBack in the texture cache's image join, a request of exactly 2 TiB: corrupted bookkeeping) and asked to hold off on `ocarina-t120-build-o`. T122 (452f177, package `ocarina-local-88054da-db167a`) is the build with his gate as we ported it (0554) and his NIR guard; the working repo's head is still the T123 commit 2d2ee9c, so a next build must start from 452f177's patch set or from his fixed branch.
