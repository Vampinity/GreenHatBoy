with local paths and private details taken out.

Columns:
- **Patch**: the patch number(s) in the series that add or read it; `front` = in the app's own code; `env only` = only ever set in a settings file.
- **Default**: what the build does when the line is absent. Almost everything new is off.
- **Builds**: the first build in [BUILDS.md](BUILDS.md) that names the switch or its patch. Builds after it carry it too, except the side branches T123 and T125.
- **Play files**: the value in the owner's two final settings files (`faster`, `prettier`); `-` = not in them.
- **Runs**: how many logged test runs had it set.
- **Verdict**: the latest reason or result written for it, shortened to one line. Flags in brackets come from the ledger: `never run`, `off, no reason`, `weak reason`, `disproven`, `in final, never tested alone`.
